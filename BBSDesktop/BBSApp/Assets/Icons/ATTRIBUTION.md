# Construction nav icons

## Custom (AQC-Core / RCC)
- `column.svg` — RC column (shaft, capital, base)
- `beam.svg` — RC beam on supports
- `slab.svg` — RC slab with thickness / mesh hint
- `footing.svg` — pad footing under column stub
- `stair.svg` — staircase flight profile

Drawn as 24×24 stroke icons for this app. Free to use with the project.
